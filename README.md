## 📁 Daftar Berkas dalam Proyek Ini

1. **`Sistem_Katalog_UMKM_Gorontalo.drawio`**  
   Berkas diagram Draw.io multi-halaman siap pakai (berisi 4 tab lengkap):
   - Tab 1: **1. Diagram Konteks** (Level 0 Context Diagram)
   - Tab 2: **2. DFD Level 0** (6 Proses Utama & 5 Data Store)
   - Tab 3: **3. DFD Level 1 (Proses 3.0)** (Breakdown Pengelolaan Kategori & Produk UMKM)
   - Tab 4: **4. ERD (Katalog UMKM)** (Entity Relationship Diagram lengkap PK, FK, & Relasi 1:N)

2. **`LAPORAN_DAN_PANDUAN_TUGAS_5.md`**  
   Laporan komprehensif yang berisi:
   - Format isian jawaban untuk disalin ke LMS / form tugas.
   - Analisis kebutuhan sistem dan batasan kritis (non-transaksional).
   - Penjelasan detail Diagram Konteks, DFD Level 0, DFD Level 1, dan ERD.
   - Kamus data lengkap dan panduan menghasilkan link share publik tanpa permission request.

3. **`index.html`**  
   Portal visual interaktif berbasis web untuk meninjau diagram, menyalin teks tugas, serta mengunduh file secara lokal. Cukup klik ganda untuk membuka di browser.

4. **`generate_drawio.py`** & **`build_portal.py`**  
   Skrip Python otomatis untuk membuat ulang berkas diagram Draw.io dan portal web.
